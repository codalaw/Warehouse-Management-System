# Warehouse Management System

A terminal-based warehouse inventory management application built with Python.

This is a personal learning project designed to practice Python programming, working with JSON data, and building a practical inventory tracking system.

## Project Overview

The goal is to create a simple warehouse management application that allows users to manage products and track stock quantities.

The project is being developed incrementally as I learn Python, with an emphasis on problem-solving, debugging, and writing maintainable code.

## Current Features

- **Main Menu:** Navigate between different inventory management options.
- **View Inventory:** Display products, quantities, and storage locations.
- **Search Products:** Find products using their unique product IDs.
- **Input Validation:** Handle non-numeric product IDs without crashing.
- **JSON Data Storage:** Load product information from a local JSON file.
- **Modular Structure:** Separate the main program from inventory functions.

## Planned Features

- Add new products to inventory.
- Update existing stock quantities.
- Save inventory changes to the JSON file.
- Improve the terminal user interface.
- Add additional error handling and validation.

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

Ensure `inventory.json` exists in the same directory as the Python files.
